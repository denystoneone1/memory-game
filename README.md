# Memory Game

Игра на поиск пар: на поле 16 карточек (8 пар), лежащих рубашкой вверх. Игрок открывает по две карточки и запоминает их расположение, чтобы найти все пары за наименьшее число ходов.

## Возможности

- Карточки перемешиваются случайным образом при загрузке страницы и при каждой новой игре.
- Совпавшая пара остаётся открытой, несовпавшая закрывается примерно через секунду.
- Счётчики ходов и найденных пар (из 8).
- Модальное окно победы с итоговым числом ходов.
- Таблица лидеров: топ-10 результатов (место, число ходов, дата), хранится в `localStorage`.
- Кнопка «Новая игра» перезапускает игру без перезагрузки страницы.

Вся разметка создаётся через JavaScript (`document.createElement`), без сторонних UI-библиотек.

## Технологии

HTML, CSS, JavaScript (ES-модули), [Vite](https://vite.dev/) для разработки и сборки, ESLint, Prettier, Husky, commitlint.

## Локальный запуск

Требуются [Node.js](https://nodejs.org/) 20.19+ и [pnpm](https://pnpm.io/).

```bash
git clone git@github.com:denystoneone1/memory-game.git
cd memory-game
git switch memory-game
pnpm install
pnpm dev
```

Откройте в браузере адрес, который выведет Vite (по умолчанию http://localhost:5173).
